# 💤 Insomnia Project

A full-stack application designed to deliver a seamless and scalable experience across web and mobile platforms. The system integrates a modern frontend, a robust backend API, and a cross-platform mobile application.

---

## 📁 Project Structure

```
insomnia/
├── insomnai-frontend/   # Web application (Next.js / React)
├── insomnia_backend/    # Backend API / server
├── insomnia_mobile/     # Mobile application
└── README.md
```

---

## 🚀 Overview

The Insomnia Project is structured as a unified codebase containing three core components:

* **Frontend** — User-facing web interface
* **Backend** — Handles business logic, APIs, and data processing
* **Mobile App** — Extends functionality to mobile devices

This architecture enables scalability, modular development, and easier maintenance.

---

## 🛠️ Tech Stack

**Frontend**

* Next.js
* React

**Backend**

* Node.js
* Express.js

**Mobile**

* React Native (or equivalent framework)

## ⚙️ Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/Roshan2607/Insomnia-Project.git
cd Insomnia-Project
```

---

### 2. Install Dependencies

#### Frontend

```bash
cd insomnai-frontend
npm install
npm run dev
```

#### Backend

```bash
cd insomnia_backend
npm install
npm start
```

#### Mobile

```bash
cd insomnia_mobile
npm install
npm start
```

---

## 🔑 Environment Configuration

Create a `.env` file in the required directories and define:

```
PORT=5000
DATABASE_URL=your_database_url
API_KEY=your_api_key
```
